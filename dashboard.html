How TradingAgents Works
Fetches live Yahoo Finance data for any ticker or futures contract (ES=F, NQ=F, CL=F, GC=F, NVDA...) — calculates ATR14, SMA20, momentum — then runs 6 specialized LLM agents (Bull, Bear, Market, News, Research, Fund Manager) that debate the trade. Each agent validates the pre-calculated entry/SL/TP levels with qualitative reasoning. Final output: exact trade levels, position size (1% risk), signal strength, and confidence score.

How TradingAgents Works
TradingAgents (TauricResearch) is a multi-agent LLM framework that mimics a real trading firm. You input a ticker + analysis date, and a team of 6 specialized AI agents debate the trade: Bull Analyst (bullish thesis) vs Bear Analyst (bearish thesis), Market Analyst (technicals), News Analyst (sentiment), then Research Manager synthesizes debates, and Fund Manager makes the final BUY / SELL / HOLD decision. Noah runs this full pipeline and returns each agent's reasoning + final trade signal.
